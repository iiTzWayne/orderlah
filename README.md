# OrderLah

AI order assistant for home bakers and small food sellers in Malaysia.
It turns messy WhatsApp-style orders (English, Malay and Chinese mixed) into structured orders that a seller reviews and confirms.

**Status:** in development.

## Tech stack
Next.js 16, TypeScript, Tailwind, Supabase (Postgres, Auth, Row Level Security), Gemini API.
